# human-signal.github.io

The Human Signal Games company site, published by GitHub Pages at
[human-signal.github.io](https://human-signal.github.io) from the root of `main`.

- `index.html`, `style.css`: the studio page listing our games
- `moonbeam-echoes.png`: Moonbeam Echoes icon, from the moonbeam-echoes-website repo
- `potty-rogue/`: Potty Rogue's landing, support, and privacy pages, which the App Store listing links to.
  Don't edit them here. They're copied from the `site/` folder in the potty-rogue repo by its
  `scripts/publish-site.sh`.

Preview locally with `python3 -m http.server 8000`, then visit http://localhost:8000.
